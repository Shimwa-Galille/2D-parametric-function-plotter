# 2D Parametric Function Plotter

A Python-based application for plotting parametric functions in **Cartesian** and **Polar** coordinate systems. This tool provides an interactive interface to visualize mathematical functions and their characteristics, including axes, asymptotes, and more.

---

## Features
- Plot parametric functions in **Cartesian** (`x(t), y(t)`) or **Polar** (`r(t), θ(t)`) coordinate systems.
- Customize the range (`t_min` to `t_max`) and scaling factor for precise plotting.
- Automatically detects and displays asymptotes (horizontal and oblique).
- Intuitive GUI built using the `ezTK` library.
- Supports a variety of mathematical functions (`sin`, `cos`, `exp`, etc.).
